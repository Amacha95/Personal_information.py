# Personal Information Program

This repository contains a simple Python program that stores and displays basic personal information.  
It is designed as a beginner practice project to learn variables, printing, simple math, and conditional statements in Python.

---

##  What the Program Does

The script:

- Stores personal details such as name, age, favorite food, and favorite color.
- Prints each piece of information to the screen.
- Calculates how old the user will be next year.
- Uses an `if / elif / else` statement to determine the user's age category:
  - Adult (18 or older)
  - Teenager (exactly 17)
  - Minor (under 17)

---

##  Concepts Learned

This project helps practice:

- Python variables  
- `print()` function  
- Basic arithmetic  
- Conditional logic (`if`, `elif`, `else`)  
- Clean code formatting  
- Writing comments to explain code  

---

## 📝 Code Explanation

The program begins by defining variables that store personal information.  
It then prints these values and performs a simple calculation to show the user's age next year.  
Finally, it checks the user's age and prints a message describing their age group.
